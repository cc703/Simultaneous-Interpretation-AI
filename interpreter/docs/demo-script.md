# Demo 录屏讲解脚本

本脚本用于比赛提交视频，目标是清楚展示题目二“AI 同声传译助手”的核心闭环：外语音频流输入、实时目标语言字幕、语音输出、翻译修正和导出。录屏主线使用 File 模式，Live 作为真实直播音频捕获展示，Demo 作为无 Key 或网络波动时的兜底。

建议时长：3 到 5 分钟。

可按 `docs/final-demo-path.md` 作为实际录屏操作顺序。

## 录制前准备

1. 启动本地 AI Gateway：

```bash
cd interpreter
npm install
npm run dev:server
```

2. 另开终端启动前端：

```bash
cd interpreter
npm run dev -- --host 127.0.0.1
```

3. 打开 `http://127.0.0.1:5173`。
4. 确认右上角显示 `AI 引擎在线 · dashscope`。
5. 录屏前执行 `npm run smoke:final`，确认自动闭环检查通过。

## 讲解顺序

### 1. 说明选题和目标

“本项目选择题目二：AI 同声传译助手。目标是把外语音频流实时转换为中文字幕，并提供语音播报、人工修正、术语增强和导出能力。产品默认输出中文，同时支持目标语言切换。”

画面操作：展示顶部标题、输入源、语言路由、状态栏和字幕工作区。

### 2. 展示 File 主线

“我先用 File 模式跑正式评审主线。这里加载内置英文样本，源语言保持自动检测，目标语言选择中文。点击开始同传后，系统会把英文音频送入 ASR，再生成中文字幕。”

画面操作：

1. 输入源切到 `文件`。
2. 源语言选择 `自动检测`，目标语言选择 `中文`。
3. 点击 `加载样本`。
4. 点击 `开始同传`。
5. 等待字幕逐条出现。
6. 指出字幕区有检测语言文本和目标语言字幕，底部大字幕会同步显示。

### 3. 展示语言路由和语音输出

“同声传译需要选择目标语言，源语言默认自动检测。这里可以切换目标语言，也可以切换字幕显示为双语、目标语言或检测语言。打开语音输出后，浏览器会按目标语言播报字幕。”

画面操作：

1. 展示源语言和目标语言选择器。
2. 点击 `双语`、`目标语言`、`检测语言` 三个字幕模式。
3. 打开 `Settings` 中的语音输出和语速调节。

### 4. 展示翻译修正能力

“同传场景中译文可能需要人工快速修正。这里我选择一条字幕，直接修改目标语言译文，然后保存。”

画面操作：

1. 点击一条字幕卡片。
2. 在翻译修正区修改目标语言译文。
3. 点击 `保存修正`。
4. 展示字幕卡片标记为用户修正，修正计数增加。

### 5. 展示术语表和重译

“专业会议里术语一致性很重要。系统支持添加术语，并对选中字幕进行术语重译。人工修正和术语会沉淀为后续翻译可参考的上下文。”

画面操作：

1. 在 `设置 -> 术语` 添加 `pitch deck` -> `融资演示文稿`。
2. 选择包含该词的字幕。
3. 点击 `术语重译`。
4. 展示术语命中标签和修正后的目标语言字幕。

### 6. 展示上传文件

“文件模式也支持上传本地英文音频或视频。启动配置了 DASHSCOPE_API_KEY 的本地后端代理后，系统会通过 `/api/transcribe` 调用百炼 Qwen-ASR 做真实转写，再进入目标语言翻译、修正、术语和导出流程。”

画面操作：

1. 切换到 `文件`。
2. 上传一个音频或视频文件。
3. 确认右上角 AI 引擎在线。
4. 点击 `开始同传`。
5. 展示文件名、ASR 状态、进度条、波形和字幕输出。

边界说明：“当前前端上传仍限制为 25MB；浏览器和后端都未配置 Key 时会明确提示配置缺口，不会伪装成真实 ASR。”

### 7. 展示直播捕获和分片 ASR

“Live 模式可以捕获浏览器标签页或屏幕音频。启动配置了 DASHSCOPE_API_KEY 的本地后端代理后，系统会使用 MediaRecorder 按分片长度持续转写直播音频，再送入目标语言翻译链路。”

画面操作：

1. 打开 `http://127.0.0.1:5173/live-room.html` 播放测试源。
2. 回到主应用，切换到 `直播`。
3. 点击 `选择直播音频`。
4. 选择一个带英文音频的标签页或屏幕，并勾选共享音频。
5. 展示 Source、Permission、ASR、Queued、Done、Silent、Dup、Latency 和 `停止直播捕获`。

边界说明：“Live 依赖浏览器共享音频权限、MediaRecorder、ASR Key 和网络质量；它只处理音频，不做画面理解；属于几秒级准实时分片转写。”

### 8. 展示导出

“最后，系统支持把当前字幕结果导出为 SRT，也可以复制双语文本，方便会后使用。”

画面操作：

1. 点击 `导出` 下载 SRT。
2. 点击 `复制` 复制双语文本。
3. 说明导出内容使用当前修正后的字幕。

### 9. 兜底 Demo

“如果评审现场网络或 Key 不稳定，Demo 模式仍可以展示完整闭环。它不会伪装真实 ASR，只用于稳定证明产品链路。”

画面操作：

1. 输入源切到 `演示`。
2. 选择 `Product Launch`、`Technical Talk` 或 `Business Meeting`。
3. 点击 `开始同传`。
4. 展示同样的字幕、修正、术语和导出能力。

### 10. 总结开发过程

“开发过程按功能逐步推进：状态管理、UI、STT、流式翻译、修正闭环、Demo、文件真实 ASR、直播分片 ASR、质量诊断、修正记忆、导出、波形、TTS 和最终演示材料。主分支始终保持可运行，每一步都经过构建验证。”

## 必须避免的说法

- 不要说“无限制支持任意大小文件音频真实识别”。
- 不要说“直播同传无延迟”。
- 不要说“Live 能理解视频画面内容”。
- 可以说“文件模式支持通过本地 Gateway 调用百炼 Qwen-ASR，当前前端上传限制为 25MB，DashScope inline 音频建议控制在 10MB 内”。
- 可以说“直播模式支持 MediaRecorder 分片 ASR，属于几秒级准实时字幕”。
- 可以说“Demo 模式用于保证评审时稳定展示题目要求的完整产品闭环”。
